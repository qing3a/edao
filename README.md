# 恶盗临天

内容兵工厂 · 矩阵选题引擎 v2 —— 纯前端 Web 应用，无构建依赖、无需安装，浏览器打开即可运行。

## 文件结构

| 文件 | 作用 |
|---|---|
| `象限文案生成器 .html` | 页面结构与样式，尾部引用两个外部 JS |
| `data.js` | 语料库 / 变量池（阶段、行为定性、痛点感受、反制策略、内容类型、情绪SKU、风控词典） |
| `app.js` | 引擎逻辑（矩阵选题、5 步流水线、提示词生成、风控扫描、历史配方） |

> 三个文件需保持同目录；加载顺序 `data.js` 在前、`app.js` 在后。改语料只动 `data.js`，改逻辑只动 `app.js`。

## 核心机制

**矩阵选题公式**：纵轴(用户旅程) × 变量A(行为定性) × 变量B(痛点感受) × 变量C(反制策略) × 变量G(内容类型) × 变量E(情绪SKU，含人性引擎D)

**分步流水线**：痛点引入 → 敌化隔离 → 赋能反制 → 干货留白 → 闭环引流，每步可切换 5 个内容版本并导出 AI 提示词。

## 快速开始

```bash
# 本地直接打开
start "" "象限文案生成器 .html"

# 或起一个静态服务器
python -m http.server 8000
# 访问 http://localhost:8000
```
