# 恶盗临天

## 初衷 · 让恶盗的手法无处藏身

本项目的初衷，是从叙事的角度**暴露恶、显现恶，让恶为人所知**。

这里的「恶」，不是亲密关系里甲乙双方的矛盾——受害者与施害者之间的恩怨只是表象。真正的恶，是**介入方**：趁关系出现裂痕时介入，挑拨关系、制造对立、恶意归因，把复杂的痛苦压缩成一句「他有病、你是受害者」的单一剧本，再从中渔利。这些人，就是「恶盗」。

本工具把恶盗的整套叙事手法**公开、原样、完整地摊开**：

- **情绪按钮**——贪、嗔、痴三引擎：文案如何按下读者的欲望、愤怒与幻想
- **对立制造**——敌化隔离：如何把一个人从「人」的名单里除名
- **恶意归因**——如何把复杂因果简化为单一罪人，锁定情绪出口
- **留白漏斗**——干货留白：如何扣住答案，把读者推向付费
- **审核规避**——概念替换：如何让越界内容通过平台审核

手法一旦被完整写出并公开，就再也藏不住。**认得出来，就不再是猎物。**

## 文件结构

| 文件 | 作用 |
|---|---|
| `象限文案生成器 .html` | 页面结构与样式，尾部引用两个外部 JS |
| `data.js` | 语料库 / 变量池（阶段、行为定性、痛点感受、反制策略、内容类型、情绪SKU、风控词典） |
| `app.js` | 引擎逻辑（矩阵选题、5 步流水线、提示词生成、风控扫描、历史配方） |

> 三个文件需保持同目录；加载顺序 `data.js` 在前、`app.js` 在后。改语料只动 `data.js`，改逻辑只动 `app.js`。

## 核心机制

**矩阵选题公式**：纵轴(用户旅程) × 变量A(行为定性) × 变量B(痛点感受) × 变量C(反制策略) × 变量G(内容类型) × 变量E(情绪SKU，含人性引擎D)

**分步流水线**：痛点引入 → 敌化隔离 → 赋能反制 → 干货留白 → 闭环引流，每步可切换 5 个内容版本并导出 AI 提示词。

## 快速开始

```bash
# 本地直接打开
start "" "象限文案生成器 .html"

# 或起一个静态服务器
python -m http.server 8000
# 访问 http://localhost:8000
```
